# diegonava150.github.io

My personal portfolio → **https://diegonava150.github.io**

A single-page, dependency-free site (plain HTML/CSS/JS) served by GitHub Pages.

## Updating

- **Add a headshot:** drop `assets/headshot.jpg`, then in `index.html` replace the
  `<span aria-hidden="true">DN</span>` inside `.avatar` with
  `<img src="./assets/headshot.jpg" alt="Diego Navarro" />`.
- **Add your CV:** drop `Diego-Navarro-CV.pdf` in the repo root (the "Download CV"
  button already points at it).
- Edit content directly in `index.html` and push — Pages redeploys automatically.
